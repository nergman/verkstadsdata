# Welding Calculator

## Overview
The Welding Calculator is a web application designed to assist users in calculating Nickel and Chromium equivalents for various steel compositions. This tool is particularly useful for welders and metallurgists who need to ensure the quality and compatibility of different steel types in welding applications.

## Features
- Input fields for entering the composition of steel (percentage of elements).
- Calculation of Nickel and Chromium equivalents based on user input.
- User-friendly interface with clear instructions and results display.

welding-calculator

## Usage Instructions
1. Open `index.html` in a web browser.
2. Enter the percentage of Nickel and Chromium in the respective input fields.
3. Click the "Calculate" button to compute the equivalents.
4. The results will be displayed below the input fields.

## Setup Information
No additional setup is required. Simply open the `index.html` file in any modern web browser to use the application.
